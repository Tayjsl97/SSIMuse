# Pop1K7 / AILabs controlled data

The controlled experiment uses 400 reference and 400 mixture crops derived
from AILabs.tw Pop1K7. The local optimized crops would occupy approximately
25 MB, but they are not redistributed here because the current Zenodo record
does not display an explicit dataset license.

Download: [Pop1K7.zip (302.7 MB)](https://zenodo.org/records/13167761/files/Pop1K7.zip?download=1)

Dataset page: [AILabs.tw Pop1K7, Zenodo record 13167761](https://zenodo.org/records/13167761)

After obtaining permission or confirming the applicable dataset license,
place the processed `(256, 128)` `uint8` arrays in:

```text
reference_crops/
mixture_crops/
```
